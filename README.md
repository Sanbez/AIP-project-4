# Apple Marketplace

Учебный проект — маркетплейс для покупки и продажи техники Apple. Делал в рамках курса, поэтому репозиторий разбит по главам — каждая ветка это отдельный этап разработки.

## Стек

- **Vue 3** + Composition API
- **Vuetify 3** — UI компоненты
- **Pinia** — стейт менеджмент
- **Vue Router 4** — роутинг с гардами
- **Express.js** — бэкенд API
- **PostgreSQL** — база данных
- **Multer** — загрузка фото
- **JWT** — авторизация

## Что умеет

- Каталог объявлений с фильтром по категориям (iPhone, iPad, Mac, Watch, AirPods, Аксессуары)
- Карусель на главной из 5 слайдов с живыми фото
- Регистрация и вход с валидацией форм
- Создание объявления с drag-and-drop загрузкой фото
- Страница товара с покупкой и редактированием
- Список заказов с чекбоксом «Получен»
- Навигационное меню меняется в зависимости от авторизации
- Если бэкенд недоступен — показываются демо-данные

## Запуск

Нужен Node.js и PostgreSQL.

```bash
npm install
```

Создать `.env` в корне:

```
VITE_API_URL=http://localhost:3001
JWT_SECRET=твой_секрет
DATABASE_URL=postgres://user:password@localhost:5432/apple_marketplace
```

Создать базу данных и накатить схему:

```bash
psql -U postgres -d apple_marketplace -f server/schema.sql
```

Запустить фронт и бэкенд вместе:

```bash
npm run dev:all
```

Или по отдельности:

```bash
npm run dev        # фронтенд на :5173
npm run server:dev # бэкенд на :3001
```
